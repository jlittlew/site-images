# Site images

Public images for Jesse Littlewood's directory sites (coldhandsgear.com, activismtools.org), served by Cloudflare from the `public/` folder. Every push to `main` redeploys.

- `public/coldhandsgear/icons/` – category icons used as listing logos (512 px squares, original artwork)
- `public/coldhandsgear/photos/` – maker photos used with written permission (credit line on each listing)
- `public/activismtools/logos/` – square logo tiles for activismtools.org

Rules: only original artwork or images we have permission to use. Never overwrite a file a live listing points to; add a new name (e.g. `-v2`) instead.
