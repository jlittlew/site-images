# Site images

Public images and files for Jesse Littlewood's directory sites (coldhandsgear.com, activismtools.org), served by Cloudflare from the `public/` folder. Every push to `main` redeploys.

Web addresses (each one serves the whole `public/` folder):
- Cold Hands Gear: `https://img.coldhandsgear.com/coldhandsgear/...`
- Activism Tools: `https://files.furtherfwd.com/activismtools/...`

- `public/coldhandsgear/icons/` – category icons used as listing logos (512 px squares, original artwork)
- `public/coldhandsgear/photos/` – maker photos used with written permission (credit line on each listing)
- `public/activismtools/logos/` – square logo tiles for activismtools.org (new and fixed logos only; older logos stay on Directify)
- `public/activismtools/files/` – downloads for activismtools.org visitors (PDF checklists, templates)

Rules: only original artwork, images we have permission to use, or a tool's own logo, shown only on its listing. Never overwrite a file a live listing or page points to; add a new name (e.g. `-v2`) instead.

Everything here is public, history included: public-ready files only, nothing from clients. Cloudflare's limit is 25 MiB per file.
